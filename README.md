# Flite Line Flow Systems — website

Static marketing site for a custom flow and pressure aviation test-equipment business
(flow benches, pressure/proof test stands, calibrated flow hardware, ground support test sets).

- `index.html` — single-page site
- `styles.css` — design tokens, dark/light themes
- `app.js` — theme toggle, scroll reveals, demo quote form
- `img/` — generated imagery (WebP)

Hosted with GitHub Pages from the `main` branch root.
